Codex for Sublime Text – 1.36.0
================================

## Major

Now this thing working on Windows properly.

### Detail

- CLI startup is more forgiving: the default `codex_path` now defers to `which(codex)`, non-absolute executables are resolved automatically, and API tokens are only exported when they look real.
- Startup race conditions are gone—the bridge queues outbound requests until the CLI signals the session is ready, flushes them reliably, and tears them down safely on shutdown while forcing UTF-8 output decoding.
- Patch workflows are friendlier: approval requests pop a quick panel with diff previews, offer per-session auto-approve, and reuse the new diff formatter for both approval and apply events.
- Transcripts now surface otherwise unhandled payloads in readable JSON so odd events can be inspected instead of disappearing silently.
- Docs now cover cross-platform setup, and the redundant Windows-only settings stub has been retired.
