Codex for Sublime Text - 1.160.0
=================================

This release fixes the Package Control installation failure reported in issue
#34 and includes the accumulated transcript and editor-tool improvements.

Highlights

- Package Control now installs Codex as an unpacked directory. This prevents
  `ModuleNotFoundError: No module named 'Codex.plugin.vendor'` when Sublime loads
  the bundled libraries.
- Codex can use bundled Sublime tools to open diffs, add or clear annotations,
  list views, and close selected views. The bundled `sublime-explain-diff` skill
  is registered with app-server.
- Each Codex bridge stays bound to its own Sublime window.
- Transcript folding uses shared section geometry, preserves manual overrides,
  and keeps streaming agent messages anchored in order.
- Local transcript links reuse files already open in Sublime.

Compatibility and validation

- Plugin `1.160.0`
- codex-cli `0.160.1`: verified app-server initialization, skill-root registration,
  and thread creation with the plugin's dynamic tool namespace.
- Sublime Text build 4205 or newer; live unpacked-package import smoke tested on
  build 4214 with Python plugin host `3.14`.
- Host and bundled-library unit tests passed. Compilation and release metadata
  checks passed.
