Codex for Sublime Text – 1.25.0

Thanks for installing/updating! This release includes two notable changes that may affect your setup:

- Settings key for API token: The OpenAI API token is configured via the `token` setting. The plugin exports this value to the environment variable specified by `env_key` (default: `OPENAI_API_KEY`). If you previously stored your key under a different setting name in another package, please add `"token": "sk-..."` to your Codex settings or configure your environment accordingly.

- UI and Markdown changes: The transcript and input panels now use a bundled Markdown syntax tailored for better section folding. You can auto-fold sections by header with `fold_sections` in either project or global Codex settings.

Migration steps

1. Open: Preferences → Package Settings → Codex → Settings.
2. Ensure your settings include your API token, for example:

   {
     "token": "sk-...",
     "env_key": "OPENAI_API_KEY"
   }

3. (Optional) Configure auto-folding of sections by header title:

   {
     "fold_sections": ["agent_reasoning"]
   }

Notes

- If you prefer not to store a token in settings, set the environment variable indicated by `env_key` before launching Sublime Text.
- See the README for details on models, providers, sandboxing, and folding options.
