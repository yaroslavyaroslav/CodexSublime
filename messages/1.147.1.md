Codex for Sublime Text - 1.147.1
=================================

This patch improves transcript navigation and keeps Markdown output sections
stable when commands emit nested or incomplete code blocks.

Highlights

- Local Markdown file links now open directly in Sublime Text at their encoded
  line and column.
- Cmd-click opens a local file link in a split view within the current group.
- Chat Markdown now extends Sublime Text's system Markdown syntax while keeping
  the section scopes used for transcript folding.
- Every new output section starts at a hard Markdown boundary, preventing an
  unterminated command-output code block from swallowing later sections.
- Normal and streaming transcript sections now share the same vendored UI
  presentation helper.

Compatibility

- Plugin `1.147.1`
- codex-cli `0.147.0`
- Sublime Text build 4205 or newer (live smoke tested on build 4206)
- Python plugin host `3.14`
