Codex for Sublime Text - 1.104.0
=================================

This release updates the plugin to work with codex-cli `0.104.0` via the
`app-server` bridge.

Highlights

- Switched backend integration from legacy `proto` flow to `codex app-server`.
- Implemented app-server bootstrap and conversation lifecycle
  (`initialize`/`initialized`, resume/new conversation, listener setup).
- Fixed approval handling for both legacy and v2 server requests.
  - Correctly maps decisions (`approved`, `approved_for_session`, `denied`, `abort`)
    to app-server responses.
  - Avoids duplicate approval prompts caused by duplicated notification/request flows.
- Improved transcript rendering:
  - Reduced noisy internal event output by default.
  - Added explicit approval decision entries in transcript (`*_approval_result`).
- Improved robustness and diagnostics:
  - Better error propagation when message send fails.
  - Optional debug traces now honor `"log_level": "debug"`.
- Cross-platform fixes:
  - Safer `writable_roots` serialization for Windows paths.
  - Process launch flags adjusted for Windows compatibility.

Compatibility

- Plugin `1.104.0`
- codex-cli `0.104.0`
