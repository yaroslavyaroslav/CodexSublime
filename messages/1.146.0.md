Codex for Sublime Text - 1.146.0
=================================

This release updates the plugin for codex-cli `0.146.0`.

Highlights

- Added support for current app-server v2 notifications, including streamed
  assistant replies, command execution, file changes, MCP calls, turn errors,
  and turn completion.
- Fixed completed-turn cleanup so consecutive messages in the same chat keep
  receiving responses.
- Removed the obsolete default `gpt-5` override. By default, the plugin now
  uses the model selected by the authenticated Codex account.
- Preserved compatibility handling for legacy `codex/event/*` notifications.

Compatibility

- Plugin `1.146.0`
- codex-cli `0.146.0`
