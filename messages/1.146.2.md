Codex for Sublime Text - 1.146.2
=================================

This release unifies the chat presentation and adds prompt history to the
Codex input panel.

Highlights

- Added Up/Down navigation through previously submitted prompts while the
  caret is at the start of the input.
- Preserved unfinished drafts when the input panel is cancelled with Escape
  and restored the draft when it is opened again.
- Moved shared Markdown formatting, panel presentation, prompt-history state,
  and syntax resources into the vendored `sublime-chat-ui` component.
- Migrated restored transcript views and output panels to the shared Chat
  Markdown syntax while retaining compatibility with the legacy resource path.
- Added a repository script for updating the vendored shared UI snapshot.

Compatibility

- Plugin `1.146.2`
- codex-cli `0.146.0`
- Sublime Text build 4205 or newer
- Python plugin host `3.14`
