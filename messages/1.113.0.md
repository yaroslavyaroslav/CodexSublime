Codex for Sublime Text - 1.113.0
=================================

This release updates the plugin to work with codex-cli `0.113.0`.

Highlights

- Updated the app-server bridge for the current Codex thread/turn protocol.
  - Uses modern thread bootstrap and turn submission on newer codex-cli builds.
  - Keeps compatibility fallback for older app-server conversation methods.
- Fixed startup failure that surfaced in the transcript as:
  - `_Unhandled message payload shown for inspection._`
  - `{"reason": "bridge_not_ready"}`
- Improved bridge error reporting:
  - Bootstrap failures now render as explicit transcript errors.
  - Recent Codex stderr is included to make CLI/protocol failures diagnosable.
- Fixed workspace root detection for `workspace-write` sessions:
  - Prefer the containing project folder for the active file.
  - Fall back to the Git root when no matching Sublime folder is present.
  - Avoid overly narrow write scopes caused by using the file's directory as `cwd`.

Compatibility

- Plugin `1.113.0`
- codex-cli `0.113.0`
